# Ryoku Paper Dark for Omarchy

An editorial paper theme for [Omarchy](https://omarchy.org): carbon washi `#171512`, bone ink `#F3ECE2` and aged-gold `#C79A49` accents,
with a kintsugi marble statue against a Great Wave print.

Ported from the Ryoku Paper Dark rice. Omarchy generates every app config
(terminals, Hyprland, the shell, Neovim, VS Code, btop, Chromium) from
`colors.toml`. Terminal ANSI colors use the rice's high-contrast palette.

## Install

```bash
omarchy theme install https://github.com/eduardojvieira/omarchy-ryoku-paper-dark-theme
```
